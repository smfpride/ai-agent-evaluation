# Operations Documentation

This folder contains operational procedures, monitoring configurations, and performance optimization guides for running the AI Agent Evaluation System in production.

## Files

- **[production-runbook.md](production-runbook.md)** - Day-to-day operations guide with troubleshooting procedures
- **[monitoring-configuration.md](monitoring-configuration.md)** - Application Insights monitoring setup and alert configuration
- **[performance-optimization-guide.md](performance-optimization-guide.md)** - Performance tuning strategies for high-volume workloads

## Operations Workflow

### Daily Operations
1. Review [production-runbook.md](production-runbook.md) for operational procedures
2. Monitor dashboards configured per [monitoring-configuration.md](monitoring-configuration.md)
3. Apply optimizations from [performance-optimization-guide.md](performance-optimization-guide.md) as needed

### Incident Response
1. Use troubleshooting section in [production-runbook.md](production-runbook.md)
2. Check Application Insights using queries from [monitoring-configuration.md](monitoring-configuration.md)
3. Escalate per runbook procedures if unresolved

### Performance Tuning
1. Baseline current performance metrics
2. Apply relevant optimizations from [performance-optimization-guide.md](performance-optimization-guide.md)
3. Measure impact and adjust
