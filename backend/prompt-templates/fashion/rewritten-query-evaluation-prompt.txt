## Evaluation Criteria

You must evaluate the quality and relevance of the **RewrittenUserQuery:** in the actual response. Consider the following aspects:

1. **Semantic Preservation**: Does the rewritten query maintain the core meaning and intent of the original user input?
2. **Clarity Enhancement**: Is the rewritten query clearer or more structured than the original while staying true to the intent?
3. **Information Retention**: Are all key details from the user's request (color, gender, product type, style, etc.) preserved?
4. **Query Optimization**: Is the rewritten query optimized for search/retrieval without losing or distorting information?
5. **Relevance**: Is the rewritten query still relevant to what the user actually wanted to find?

- **0.7-0.8**: Accurate - Rewritten query preserves the main intent with minor differences or improvements
- **0.9-1.0**: Highly accurate - Rewritten query perfectly captures and potentially improves upon the original query
